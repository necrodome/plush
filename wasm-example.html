Available Features

  • ✓ Arrays and objects
  • ✓ Actors and message passing
  • ✓ String operations
  • ✓ All math operations
  • ✓ Control flow (if/else, loops)
  • ✗ Graphics ($window_*) - not available in Wasm
  • ✗ Audio ($audio_*) - not available in Wasm

Building This Example

  1. Build the Wasm module: ./build-wasm.sh
  2. Start a local server: python3 -m http.server 8000
  3. Open: http://localhost:8000/wasm-example.html
